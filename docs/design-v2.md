# V2 디자인 반영 사항

## 참고 기준

- 사용자 제공 대형 사진 중심 기업 홈페이지: 넓은 사진과 핵심 문구, 하단 바로가기.
- 사용자 제공 수원화성 사진: 히어로 및 상세 배너에 사용, 원본 파일 보존.
- ICIMC 2026 Technical Program: 상단 탐색 메뉴, 가로 사진 배너, 왼쪽 프로그램 메뉴, 날짜·시간별 일정표의 정보 구조 참고.

## 화면

홈 / 수원 반도체 탐방 / 관광시설 둘러보기 / 기업 산업관광 일정 / 이용 안내 / AI 맞춤 일정 만들기 / 나의 신청 현황.

홈은 사진을 주인공으로 구성하고 세 가지 탐색 바로가기를 제공한다. 상세 화면은 왼쪽 메뉴와 본문으로 구분하며 작은 화면에서는 가로 스크롤 메뉴로 전환한다. 기업 일정은 실제 사례가 등록되기 전까지 두 가지 가상 기업 일정 탭으로 구성한다. 일정표는 인쇄하거나 브라우저 PDF로 저장할 수 있다.

## 동작 및 검증 범위

프로그램 분야 필터 → 상세 → 일정 필수 선택 연결. 가상 데이터 기준 연구 태그·인원·스타일·일수 조건 검사. 20명 패키징 프로그램을 25명으로 선택 시 오류 안내, 20명으로 수정 시 해당 프로그램 포함을 브라우저에서 확인했다. 기업 A/B 탭별 일정표 전환을 확인했다. 실제 생성 AI·인증·신청·예약·운영사 연락은 수행하지 않는다.

## Figma

기존 V1 기획 프레임을 보존하고 V2 메인(10:56)과 일정 상세(10:57)를 추가했다. 사진 외 UI는 편집 가능한 텍스트·프레임·컴포넌트 인스턴스이다. 공통 헤더와 탐색 카드를 재사용하며 제품 폰트는 Noto Sans KR이다.
